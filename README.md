# PortViewer

Локальная утилита для просмотра занятых портов и связанных с ними процессов. В планах — обновления в реальном времени, безопасная остановка процессов, просмотр логов и история событий в одном Go-бинарнике с веб-интерфейсом.

> Проект находится на ранней стадии. Сейчас реализован базовый HTTP-сервис с YAML-конфигурацией, логированием через Zap и проверочным маршрутом `GET /ping`.

## Запуск

Требуются Go 1.27 или новее и [Task](https://taskfile.dev/).

```bash
task a:run
```

Проверить запущенный сервис:

```bash
curl http://127.0.0.1:8080/ping
```

Ответ: `pong`.

## Конфигурация

Адрес сервера и формат логов задаются в [`config.yaml`](config.yaml). Путь к файлу обязателен и передаётся через флаг `--config`.

## Планы

- обнаружение TCP- и UDP-портов вместе с процессами;
- live-обновления и Svelte-интерфейс;
- безопасная остановка процессов;
- логи управляемых процессов;
- история событий и действий.
